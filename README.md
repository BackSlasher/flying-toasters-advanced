# Flying Toasters!

[Live](https://backslasher.github.io/flying-toasters-advanced/)

A highly faithful reconstruction of the last [After Dark Flying Toasters](https://en.wikipedia.org/wiki/After_Dark_%28software%29#Flying_Toasters) screensaver into HTML + CSS + JavaScript.  
Logic, sprites and audio extracted from the 1996 abandonware binary.  
Includes music, kareoke, SFX.  
Baby mode included.  

All of the work done by Claude (mostly Fable), with me prodding it.
